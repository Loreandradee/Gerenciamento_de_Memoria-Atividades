## 📝 Descrição da Atividade (Parte B - Prática)

Este programa em Python implementa o algoritmo de substituição de página **LRU** e o compara com o algoritmo FIFO (Questão 3), conforme solicitado na questão bônus.

Especificamente, o código implementa:

* Recebe o número de frames e a sequência de páginas.
* Implementação do algoritmo LRU, mantendo o registro do "tempo" de último uso de cada página (usando dicionário).
* Substituição da página menos recentemente usada (LRU).
* **Comparação:** O programa também simula o algoritmo FIFO para comparação direta.
* Exibição comparativa do **número total de faltas** e da **taxa de faltas** para ambos os algoritmos.
* Apresentação de uma análise crítica sobre os resultados.
